# Code of Conduct

## Our standards

We are committed to a welcoming, respectful, and harassment-free community.

Examples of positive behavior:

- Being respectful and constructive
- Accepting feedback gracefully
- Helping others learn

Examples of unacceptable behavior:

- Harassment or personal attacks
- Discrimination of any kind
- Publishing private information without consent

## Enforcement

Project maintainers are responsible for clarifying and enforcing standards.
They may remove, edit, or reject comments, commits, code, and issues that do
not align with this code of conduct.

## Scope

This code of conduct applies in all project spaces, including issues, pull
requests, and discussions.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the
project maintainers.
